# Adaptive Quotient Filter

The Adaptive Quotient Filter (AQF) is an approximate membership filter
that can adapt to false positive mistakes to avoid repeating them.

## Documentation

- [Getting Started](getting-started.md): Build and use a small AQF program.
- [Building](building.md): Build options, tests, and dependencies.
- [API Reference](api.md): Public C and C++ interfaces.
- [How the AQF works](how-it-works.md): High-level explanation of fingerprints,
  false positives, and adaptation.
- [QF Internals](qf.md): Simplified explanation of quotienting, runs, metadata,
  and fingerprint extensions.
- [Reverse Map](reverse-maps.md): Reverse-map implementations and custom
  integration requirements.
