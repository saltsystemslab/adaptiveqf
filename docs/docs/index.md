The ***Adaptive Quotient Filter*** (AQF) is an approximate membership tester
that **adapts to its false positive mistakes** while also having similar space
usage and query speed as traditional filters. Unlike traditional filters, the
AQF provides **robust false positive rate guarantees**: the observed rate will
never exceed the configured rate.
